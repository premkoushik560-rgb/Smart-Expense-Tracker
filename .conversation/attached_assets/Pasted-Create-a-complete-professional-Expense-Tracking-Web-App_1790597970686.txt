Create a complete, professional **Expense Tracking Web Application** as an internship project.

### Project Title

**Smart Expense Tracker**

### Objective

Build a user-friendly web application that allows users to manage their personal finances by tracking income, expenses, budgets, and spending patterns.

### Technology Stack

* Frontend: HTML5, CSS3, JavaScript
* Backend: Python Flask
* Database: SQLite with SQLAlchemy
* Charts: Chart.js
* Authentication: Flask-Login
* Password Security: Werkzeug password hashing
* Version Control: Git/GitHub

### Required Features

1. **User Authentication**

   * User registration
   * Login/logout
   * Secure password hashing
   * User-specific data

2. **Dashboard**

   * Display total income
   * Display total expenses
   * Display current balance
   * Display monthly expenses
   * Display recent transactions
   * Display highest spending category

3. **Expense Management**

   * Add an expense
   * Edit an expense
   * Delete an expense
   * Expense amount
   * Date
   * Category
   * Payment method
   * Description

4. **Income Management**

   * Add income
   * Edit income
   * Delete income
   * Income source
   * Amount
   * Date
   * Description

5. **Categories**
   Include categories such as:

   * Food
   * Travel
   * Shopping
   * Education
   * Bills
   * Entertainment
   * Healthcare
   * Other

6. **Budget Management**

   * Set monthly budget
   * Set category-wise budgets
   * Display remaining budget
   * Show warning when spending exceeds the budget

7. **Reports and Analytics**

   * Monthly income vs expense chart
   * Category-wise expense chart
   * Monthly spending trend
   * Total savings
   * Highest spending category
   * Use Chart.js for visualizations

8. **Search and Filters**

   * Search transactions
   * Filter by category
   * Filter by date
   * Filter by transaction type

9. **AI Expense Advisor**
   Add an optional AI-powered feature that analyzes the user's spending history and provides:

   * Monthly spending summary
   * Spending pattern analysis
   * Possible areas to reduce expenses
   * Savings suggestions
   * Natural-language answers about spending

10. **Responsive UI**

* Modern and clean design
* Mobile responsive
* Desktop responsive
* Navigation sidebar/navbar
* Cards for financial statistics
* Attractive charts
* Proper form validation
* Success/error notifications

### Database Design

Create appropriate SQLAlchemy models for:

* User
* Expense
* Income
* Category
* Budget

Use proper relationships between tables and ensure that each user's financial data is isolated from other users.
